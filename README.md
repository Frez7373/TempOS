# TempOS

Modern modular operating system for CC:Tweaked 1.16.5.

## Status

TempOS 1.0.0 — initial stable architecture.

## Install

```text
wget run https://raw.githubusercontent.com/Frez7373/TempOS/main/install.lua
```

The installer downloads the release manifest and installs the bootloader, kernel, GUI, services, drivers and built-in applications.
